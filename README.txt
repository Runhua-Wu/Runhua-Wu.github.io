Do not upload the ZIP file itself. Extract it first, then upload the contents while preserving every folder.

GITHUB WEBSITE UPLOAD
---------------------
1. Open the Runhua-Wu.github.io repository.
2. Select Add file -> Upload files.
3. Drag every file and folder listed above into the upload area.
4. Use the commit message: Refine homepage, About, and Research pages
5. Commit directly to the main branch.
6. Wait about one or two minutes and hard-refresh https://runhua-wu.github.io/

HEADER ICON
-----------
The small icon beside "Runhua Wu" in the upper-left corner is site-icon.png. It is also used as the browser-tab icon.

To replace it later:
1. Prepare a square PNG image.
2. Name it site-icon.png.
3. Upload it to the repository root and replace the existing file.

Keeping the same filename means no HTML editing is required.

PROFILE PHOTO LATER
-------------------
The large homepage photo area remains intentionally blank.
When a headshot is ready:
1. Name it profile.jpg.
2. Upload it to the repository root.
3. In index.html, replace the empty portrait-frame div with the image line shown in the nearby HTML comment.

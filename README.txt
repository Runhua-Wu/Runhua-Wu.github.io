RUNHUA WU ACADEMIC WEBSITE — VERSION 2

This version follows your requested multipage structure and is visually inspired by the clean, minimal organization of Rui Gong's academic website without copying its theme code.

FILES AND FOLDERS TO UPLOAD
---------------------------
Upload ALL of the following to the top level of your Runhua-Wu.github.io repository:

- index.html
- 404.html
- favicon.svg
- Runhua_Wu_CV.pdf
- assets (folder)
- about (folder)
- research (folder)
- publications (folder)
- talks (folder)
- teaching (folder)

Do not upload the ZIP file itself. Extract it first, then upload the contents.

GITHUB WEBSITE UPLOAD
---------------------
1. Open the Runhua-Wu.github.io repository.
2. Select Add file -> Upload files.
3. Drag every file and folder listed above into the upload area.
4. Use the commit message: Build multipage academic website
5. Commit directly to the main branch.
6. Wait about one or two minutes and refresh https://runhua-wu.github.io/

PHOTO LATER
